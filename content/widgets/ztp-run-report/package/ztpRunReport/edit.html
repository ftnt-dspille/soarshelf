ZTP Run Report -- Settings

How far back the run list reaches. Applied by the server, so a narrow range is also a smaller query. Viewers can widen it without opening settings; this sets where they start.
Which reading the widget opens with. All four stay one click apart in the widget header, so this only sets the starting point.
Runs view only. The newest N runs open themselves, and any run with a failed device opens regardless. 0 leaves everything collapsed.
Runs view only. Loads the step detail for this many devices in the opened runs before anyone clicks, so the first drill-down is instant. Failed devices are fetched first. 0 fetches only on click.
A device accumulates one step record per step per run. "Latest" answers "did the run that just happened break?"; "every run" answers "has this device ever broken?".
How many runs the list draws at a time ("Show more" draws the next batch). The headline, charts and exports always count every run in the selected time range.
The platform serves 30 per page unless asked otherwise. If the widget reports partial data, raise this.
Name of an active Manual playbook on ZTPF Devices. It is looked up by name when the button is used, and receives the selected devices as its records.
