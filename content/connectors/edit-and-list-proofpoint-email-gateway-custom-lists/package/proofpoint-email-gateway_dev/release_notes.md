#### Following enhancements have been made to the Proofpoint Email Gateway connector in version 2.0.0:

- Added the following new actions and associated playbooks:
    - `Get Organizational Block List`
    - `Add or Remove Organizational Block List`

- Deprecated the following actions and associated playbooks:
    - `Search Quarantine Messages`
    - `Quarantine Message Actions`

- Updated the configuration parameters as follows:
    - Added the configuration parameters: `API Key` and `Secret`.
    - Removed the configuration parameters: `Username`, `Password`, and `Port`.
